# Phase 5A — web-only product studio preview

The product editor now displays a collapsible Studio card on web, with a native null stub. Uzbek/Russian UI, manual product name and optional confirmed fitment, three templates, two formats, explicit review, PNG preview/download. It reads initial name/model from the product form when opening but does not edit the product or publish anything. The local draft is discarded when the card closes or the editor starts a new product. Existing image upload and product save are unchanged.

The optional experimental background-removal control is only exposed on loopback hosts; model/runtime assets still need manual setup and real inference verification. Manual artwork works without these assets and without provider calls. No Gemini client integration or production publishing in this change. Browser-only implementation is lazy in the sense that work starts on explicit action; no model download on page load. UI tests are structural checks, not browser automation. Next: real web preview test, staging provider client and draft review flow, explicit approved image upload preserving original and existing image limits. No deployment performed.
