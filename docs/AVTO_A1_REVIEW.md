Manba: `anvarjonaxtamov70/Avto_A1` (Telegram Mini App) va `AvtoA1optum` (optom). N99 ularning savdo mantiqini mustaqil mobil ilovaga ko‘chiradi; Telegram, bot va WebView ishlatilmaydi.

| Avto A1’dagi vazifa | N99’dagi yechim |
| --- | --- |
| Katalog, bo‘lim, model/artikul qidiruvi | Native ro‘yxat, kategoriya taksonomiyasi, GM modellari, kirill/lotin va artikul qidiruvi |
| Mahsulot, rasm, tavsif, qoldiq | Galereya, moslik, qoldiq, o‘xshash tovarlar; rasmlar havola yoki Cloudinary orqali |
| Sevimlilar, savat | Telefonda saqlanadi, qoldiq bilan avtomatik moslanadi, tanlab buyurtma |
| Telegram orqali shaxsni aniqlash | Firebase anonim hisob (mijoz), email/parol (admin) |
| Buyurtma va botga xabar | Firebase’ga bitta atomar yozuv, qoidalar narx/qoldiq/vaqtni tekshiradi; admin ilovada jonli ko‘radi |
| Stock-commit | Admin tasdiqlaganda `increment()` bilan atomar ayirish, bekor qilinsa qaytarish |
| Admin tugmalari | Ilova ichidagi boshqaruv: buyurtma, tovar, banner, sozlamalar |
| Karta/merchant to‘lovi | Hozir naqd; Payme/Click/Uzum — Cloudflare Worker bilan keyingi bosqich |
| Stories, sharh, AI, cashback | Keyingi bosqich |

Eski mijozlar, Telegram ID’lari va buyurtmalar avtomatik ko‘chirilmaydi.
